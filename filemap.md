## CI
- `.github/workflows/ios.yml` — CI: `test` job on every push (package + simulator unit tests); dispatch `compile | device-ipa | testflight | screenshots`; ad hoc signed archive + entitlement check; screen list in the `SCREENS` env of the `screenshots` job
- `.github/scripts/pick-simulator.py` — picks an available iPhone simulator (prefers iPhone 17 Pro Max, newest iOS) and prints `SIM_UDID` / `SIM_NAME` for `$GITHUB_ENV`

## ios/
- `ios/project.yml` — XcodeGen spec: targets `UnFat`, `UnFatWidgets`, `UnFatTests`, local package `UnFatCore`; Info.plist keys and entitlements (XcodeGen writes `UnFat/Info.plist`, `UnFat/UnFat.entitlements`, `UnFatWidgets/Info.plist`, `UnFatWidgets/UnFatWidgets.entitlements` at generate time)
- `ios/UnFat/App/UnFatApp.swift` — `@main` app entry
- `ios/UnFat/App/RootView.swift` — iOS 26 `TabView`: Bugün, Antrenman, İlerleme, search-role Ekle tab that opens the add sheet
- `ios/UnFat/App/AppTab.swift` — tab identifiers
- `ios/UnFat/App/LaunchRouter.swift` — DEBUG-only `-UNFAT_SCREEN <name>` parser; `LaunchRoute` lists screenshot routes
- `ios/UnFat/Features/Today/TodayScreen.swift` — Today placeholder (large title)
- `ios/UnFat/Features/Workout/WorkoutScreen.swift` — Workout placeholder
- `ios/UnFat/Features/Progress/ProgressScreen.swift` — Progress placeholder
- `ios/UnFat/Features/FoodLog/AddSheet.swift` — add sheet placeholder
- `ios/UnFat/Resources/Localizable.xcstrings` — String Catalog, source language tr
- `ios/UnFat/Resources/Assets.xcassets` — `AccentColor` (#FF6A3D, light + dark), `AppIcon` (placeholder 1024 PNG, plain accent color)
- `ios/Shared/AppGroup.swift` — App Group id and container URL (app + widgets)
- `ios/UnFatWidgets/UnFatWidgetBundle.swift` — `@main` widget bundle
- `ios/UnFatWidgets/PlaceholderWidget.swift` — temporary static widget showing "UnFat"
- `ios/UnFatTests/LaunchRouterTests.swift` — hosted unit test (launch argument parsing)
- `ios/UnFatCore/Package.swift` — local Swift package (tools 6.0, iOS 26 + macOS 15)
- `ios/UnFatCore/Sources/UnFatCore/Profile.swift` — sex, activity multipliers, goal plan, validated profile
- `ios/UnFatCore/Sources/UnFatCore/Energy.swift` — BMR, TDEE, goal-adjusted calorie target
- `ios/UnFatCore/Sources/UnFatCore/Macros.swift` — macro targets with overrides
- `ios/UnFatCore/Sources/UnFatCore/Floors.swift` — minimum-intake and below-BMR warnings
- `ios/UnFatCore/Sources/UnFatCore/Trend.swift` — EMA trend weight
- `ios/UnFatCore/Sources/UnFatCore/AdaptiveTDEE.swift` — adaptive TDEE update and eligibility
- `ios/UnFatCore/Sources/UnFatCore/Workout.swift` — MET kcal, Epley e1RM, PR detection
- `ios/UnFatCore/Sources/UnFatCore/Units.swift` — unit conversions and display rounding
- `ios/UnFatCore/Tests/UnFatCoreTests/*.swift` — formula tests with hand-computed values
- `ios/UnFat/DesignSystem/Tokens/` — Palette (accent + semantic colors), Layout (spacing, radius), Typography (rounded numbers), Motion (springs, Reduce Motion), Haptics
- `ios/UnFat/DesignSystem/Components/` — CalorieRing, MacroBar, NumberRoll, Keypad (+KeypadInput), ServingChips, RestTimerView, ListRows, PrimaryActionButton
- `ios/UnFat/Debug/` — DEBUG only: GalleryView, TuningPanel + DesignTuning, DebugScreen (full-screen routes like `gallery`)
- `ios/UnFat/Model/` — SwiftData models (synced: profile, food, workout; local: CachedProduct, HealthDaySummary), `UnFatSchema` (V1 + migration plan), `ModelContainerFactory` (Synced/Local configs in App Group), `SyncPreference`, DEBUG `Fixtures`
- `ios/UnFat/Model/Seed/` — Codable seed types (`SeedFood`, `SeedExercise`) and `LossyArray`
- `ios/UnFat/Services/SeedLoader.swift` — loads bundled `seed/*.json`
- `ios/UnFat/Services/SeedSearchIndex.swift` — Turkish-folded search over seed + custom items
- `ios/UnFat/Services/WidgetSnapshotWriter.swift` — writes the App Group snapshot and reloads widgets
- `ios/Shared/WidgetSnapshot.swift` — snapshot shared by app and widgets
- `ios/UnFatTests/{Model,WidgetSnapshot,SeedSearch,SeedLoader}Tests.swift` — data layer tests
- `tools/seed/` — seed generator: FDC extraction, recipe table, exercise table, generate/validate scripts, README (sources, licenses)
- `ios/UnFat/Resources/seed/foods_tr.json` — bundled Turkish food database (414 items), generated by `tools/seed/generate.py`
- `ios/UnFat/Resources/seed/exercises.json` — bundled exercise library (224 items), generated by `tools/seed/generate.py`
